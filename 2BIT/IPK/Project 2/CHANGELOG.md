# CHANGELOG

## Version 1.0.0 (Initial Release)
### Implementovaná funkcionalita
- Autentifikácia používateľa
- Posielanie správ
- Prepájanie sa medzi kanálmi
- Prijímanie správ zo servera
- Ukončovanie spojenia
- Menenie zobrazovacieho mena užívateľa
- Validácia a orezávanie vstupov podľa špecifikácie

### známe limitácie
- nie je zaručená odolnosť voči veľkému množstvu správ, napr. MSG alebo PING
- Centralizovaný stavový automat
- Chýba DEBUG mechanizmus
